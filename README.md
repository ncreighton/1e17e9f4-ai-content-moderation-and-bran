# AI Content Moderation and Brand Safety Discord Bot

A Discord bot that uses machine learning to moderate community content in real-time. Detects hate speech, spam, NSFW content, brand safety violations, and coordinated manipulation campaigns. Provides moderators with detailed violation reports, appeals workflow, and weekly community health dashboards. Configurable moderation thresholds, role-based exceptions, and audit logging for compliance-sensitive communities.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
